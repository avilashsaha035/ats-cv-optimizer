# Weak Verb → Strong Verb Replacement Table

## The Core Rule
Every bullet point must start with a **past-tense action verb** that shows ownership and impact.
Never start with "I", "We", "Responsible for", "Helped", or "Worked on".

## Replacement Table

| ❌ Weak / Passive              | ✅ Strong Replacement Options                        |
|-------------------------------|------------------------------------------------------|
| Worked on                     | Engineered, Developed, Built, Implemented            |
| Helped with                   | Contributed to, Supported, Facilitated, Enabled      |
| Was responsible for           | Owned, Led, Managed, Oversaw, Directed               |
| Assisted in                   | Collaborated on, Partnered to, Co-developed          |
| Did testing                   | Designed test suites, Automated testing, Validated   |
| Made improvements             | Optimized, Refactored, Enhanced, Streamlined         |
| Fixed bugs                    | Resolved, Debugged, Diagnosed and remediated         |
| Wrote code                    | Architected, Engineered, Developed, Authored         |
| Set up                        | Configured, Provisioned, Deployed, Established       |
| Used [technology]             | Leveraged, Utilized, Applied — then show outcome     |
| Participated in               | Contributed to, Collaborated on, Drove               |
| Made a system for             | Architected, Designed, Built, Delivered              |
| Maintained                    | Sustained, Monitored, Operated, Administered         |
| Handled                       | Managed, Processed, Coordinated, Administered        |
| Tried to                      | (Delete — only include completed achievements)       |
| Involved in                   | Led, Contributed to, Played a key role in            |
| Did research on               | Investigated, Analyzed, Evaluated, Researched        |
| Gave presentations            | Presented, Delivered, Communicated, Demonstrated     |
| Taught / Showed others        | Mentored, Coached, Trained, Onboarded                |
| Looked at performance         | Profiled, Benchmarked, Analyzed, Measured            |
| Made faster                   | Optimized, Reduced latency by X%, Improved throughput|

## Power Verbs by Category

**Building & Creating**
Architected · Engineered · Developed · Built · Designed · Created · Launched · Deployed · Delivered

**Improving**
Optimized · Refactored · Streamlined · Accelerated · Enhanced · Modernized · Upgraded · Migrated

**Leading**
Led · Directed · Managed · Spearheaded · Championed · Orchestrated · Coordinated · Mentored

**Achieving Impact**
Reduced · Increased · Improved · Eliminated · Saved · Generated · Boosted · Doubled · Scaled

**Analyzing**
Investigated · Analyzed · Evaluated · Profiled · Benchmarked · Diagnosed · Assessed · Audited

**Collaborating**
Collaborated · Partnered · Integrated · Aligned · Facilitated · Contributed · Supported
